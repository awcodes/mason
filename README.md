## Compatibility

| Filament version | Package version |
|------------------|-----------------|
| 3.x              | 0.x             |
| 4.x              | 1.x             |
| 5.x              | 2.x             |
| 4.x & 5.x        | 3.x             |

## Installation

```bash
composer require awcodes/mason
```

Mason needs a custom Filament theme that imports its CSS and views. See [Installation](https://docs.aw.codes/mason/3.x/installation) for that step.
